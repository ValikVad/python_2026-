# Python 2026 — учебный курс

Репозиторий-курс по Python: **Obsidian-vault с конспектами** + **пакеты домашних заданий с тестами**, инструментированный современным тулингом (uv, ruff, mypy, pytest, pre-commit, GitHub Actions).

## Требования

- Python ≥ 3.10
- [uv](https://docs.astral.sh/uv/) (рекомендуется) — быстрый менеджер проекта и окружения

## Быстрый старт

```bash
# 1. Создать окружение и поставить зависимости проекта (включая dev-группу)
uv sync

# 2. Прогнать все тесты курса
uv run pytest

# 3. Линт + типизация (только homework)
uv run ruff check obsidian/homework
uv run mypy obsidian/homework

# 4. Проверить, что локально всё чисто
uv run pre-commit run --all-files
```

> Всё делается в одном окружении через `uv run` — активировать `venv` вручную не нужно.

## Как открыть курс в Obsidian

1. В Obsidian: **Open folder as vault** → выбери папку `obsidian/`.
2. Открой `README.md` — это стартовый экран курса.
3. Конспекты линкуются между собой (`[[]]`), кнопки навигации в шапке.

## Как проходит урок (паттерн)

1. Студент читает конспект темы (`конспекты/NN-...`).
2. Открывает пакет `homework/NN_...` — там stub-функции с `raise NotImplementedError`.
3. Реализует, прогоняет `uv run pytest`.
4. Тесты в `NN_.../tests/` проверяют решение.

## CI / pre-commit

- **pre-commit** (локально): ruff (линь + формат), mypy, гигиена файлов — перед каждым commit.
- **GitHub Actions** (`.github/workflows/ci.yml`): на каждый push прогоняются ruff, mypy и pytest по всем домашним заданиям.
