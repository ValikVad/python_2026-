# Доклад · Строки и методы

> Повторение и систематизация темы №2 ядра языка.

---

## 1. Строка — неизменяемая последовательность символов

```python
s = "python"
s[0]  # 'p'
s[-1]  # 'n'
len(s)  # 6
```

**Строки неизменяемы:** `s[0] = "x"` → `TypeError`. Любая «замена» создаёт новую строку.

## 2. Создание и статусы

```python
a = "одинарные"
b = "двойные"
c = """многострочные"""
d = r"C:\raw\строка"  # raw — без экранирования
e = "\n"  # экранирование
f = f"значение: {x}"  # f-строка (3.6+)
```

## 3. Индексы и срезы (slicing)

```python
s = "python2026"
s[0:6]  # 'python'
s[6:]  # '2026'
s[:6]  # 'python'
s[::-1]  # '6202nohtyp' — разворот
s[::2]  # 'pto20'
```

**Формула среза:** `s[start:stop:step]`. Пропуски берутся от начала/до конца. Отрицательный `step` идёт в обратную сторону.

## 4. Проверки (методы-предикаты)

```python
s.isalpha()  # только буквы
s.isdigit()  # только цифры
s.isalnum()  # буквы и цифры
s.islower()  # в нижнем регистре
s.isupper()  # в верхнем
s.isspace()  # только пробелы
s.startswith("py")  # начинается ли
s.endswith("26")  # заканчивается ли
```

## 5. Поиск

```python
"abcabc".find("bc")  # 1  (первое вхождение) или -1
"abcabc".rfind("bc")  # 4  (последнее)
"abcabc".index("bc")  # 1  (как find, но ValueError если нет)
"abcabc".count("bc")  # 2  (не пересекающиеся)
```

## 6. Замена и разбиение

```python
"a b c".split()  # ['a','b','c']  (по пробелам)
"a,b,c".split(",")  # ['a','b','c']
" ".join(["a", "b"])  # 'a b'
"abc".replace("b", "X")  # 'aXc'
"  x  ".strip()  # 'x' (убрать пробелы по краям)
"x".center(5, "*")  # '**x**'
```

## 7. Регистр

```python
"Hello".lower()  # 'hello'
"Hello".upper()  # 'HELLO'
"hello".capitalize()  # 'Hello'
"hello world".title()  # 'Hello World'
"hello".swapcase()  # (меняет регистр наоборот)
```

## 8. Форматирование — f-строки (современный стандарт)

```python
name, age = "Аня", 20
f"{name} {age}"  # 'Аня 20'
f"{age:05d}"  # '00020'
f"{3.14159:.2f}"  # '3.14'
f"{name:>10}"  # выравнивание вправо на 10
f"{name:<10}"  # влево
f"{1000000:,}"  # '1,000,000'
```

Другие способы (знать, но f-строки предпочтительны):
```python
"{} {}".format(name, age)
"%s %d" % (name, age)
```

## 9. Полезные приёмы

```python
", ".join([str(x) for x in range(5)])  # '0, 1, 2, 3, 4'
"a1b2c3".isdigit() if False else ...
# разбить строку на слова:
words = text.split()
# обратный порядок слов:
" ".join(text.split()[::-1])
# проверить палиндром:
s == s[::-1]
```

## 10. Юникод и байты

- `str` хранит **Unicode-символы** (🔥 — один символ).
- Кодировка/декодирование: `s.encode("utf-8")` → `bytes`, `b.decode("utf-8")` → `str`.
- `len("🔥")` == 1 (одна кодовая точка).

---

## Шпаргалка «Строки наизусть»

1. Строки неизменяемы — любая операция создаёт новую.
2. Срезы: `s[start:stop:step]`; `s[::-1]` — разворот.
3. `split()` / `join()` — разбить/собрать.
4. `replace(old, new)` — заменить все вхождения.
5. `strip()` — убрать пробелы по краям.
6. `startswith` / `endswith` / `in` — проверки.
7. `find` возвращает -1; `index` бросает `ValueError`.
8. `f"{x:.2f}"` — округление в строке; `f"{n:05d}"` — добить нулями.
9. `str.isdigit()` vs `str.isalpha()` — цифры/буквы.
10. Кодирование: `encode("utf-8")` / `decode("utf-8")`.
11. `"...".join(...)` — склеить список строк с разделителем.
12. `s * 3` — дублирование; `len(s)` — длина.
