## 1. Главное: в Python всё — объект

Переменная — это **имя-ярлык**, приклеенное к объекту в памяти. К одной
и той же переменной можно в разное время «приклеить» объекты разных типов:

```python
x = 5  # x указывает на int
x = "hello"  # теперь на str — Python это разрешает
```

Поэтому тип определяется **значением**, а не появлением переменной.
Проверка: `type(x)`, `isinstance(x, int)`.

## 2. Базовые (встроенные) типы

| Тип        | Пример              | Неизменяемый? | О чём стоит помнить                     |
| ---------- | ------------------- | ------------- | --------------------------------------- |
| `int`      | `42`                | ✅            | Битов не ограничен                      |
| `float`    | `3.14`              | ✅            | `0.1 + 0.2 != 0.3` (двоичная арифметика) |
| `complex`  | `1 + 2j`            | ✅            |                                          |
| `str`      | `"abc"`             | ✅            | Строки нельзя менять по индексу          |
| `bytes`    | `b"abc"`            | ✅            | Последовательность байт                  |
| `bool`     | `True`              | ✅            | Это подкласс `int` (`True == 1`)         |
| `NoneType` | `None`              | ✅            | Единственное значение — `None`           |

**Изменяемые (mutable)** контейнеры: `list`, `dict`, `set`, `bytearray`,
пользовательские классы.
**Неизменяемые (immutable)**: `int`, `float`, `str`, `bytes`, `tuple`,
`frozenset`, `bool`, `None`.

> Почему изменяемость важна? Изменяемый объект можно менять «in place».
> Если передать его в функцию — изменения увидит и вызывающий код.
> Неизменяемый — только скопировать (см. п. 6).

## 3. Коллекции

### `list` — упорядоченный, изменяемый
```python
nums = [3, 1, 2]
nums.append(4)  # [3, 1, 2, 4]
```

### `tuple` — упорядоченный, неизменяемый
```python
point = (3, 4)
# point[0] = 5  -> TypeError
```

### `dict` — ключ → значение
```python
user = {"name": "Вася", "age": 30}
user.get("email", None)  # безопасный доступ (None если нет ключа)
user.setdefault("role", "user")  # вставит, только если ключа нет
```

### `set` / `frozenset` — множество уникальных значений (без порядка)
```python
unique = {1, 2, 2, 3}  # -> {1, 2, 3}
```

### `str` — неизменяемая строка символов
```python
s = "python2026"
s[0]  # 'p'
s[::-1]  # '6202nohtyp' — разворот
```

## 4. Аннотации типов (type hints)

С 3.5 можно подсказывать тип — помогает IDE и mypy (не влияет на рантайм):

```python
def add(a: int, b: int) -> int:
    return a + b
```

Современные синтаксисы:

```python
from __future__ import annotations

x: list[int]  # список целых
y: dict[str, int]  # словарь str->int
z: tuple[int, ...]  # кортеж любой длины из int
maybe: int | None  # int ИЛИ None (3.10+)
```

Встроенные дженерики `list[int]`, `dict[str, int]` доступны начиная с 3.9.

## 5. Приведение типов (casting)

```python
int("42")  # 42
float("3.5")  # 3.5
str(42)  # "42"
list("abc")  # ['a', 'b', 'c']
tuple([1, 2])  # (1, 2)
set([1, 1, 2])  # {1, 2}
```

> `int("3.5")` — ValueError. Сначала `float`, потом `int`.

## 6. Изменяемость и копирование (частая ловушка)

Изменяемые объекты передаются **по ссылке**:

```python
def add_item(lst: list) -> None:
    lst.append(1)  # меняет исходный список!


original = [0]
add_item(original)
print(original)  # [0, 1]  — Поменялось снаружи
```

Чтобы этого избежать — копия:

```python
import copy

shallow = original.copy()  # копирует слой, вложенные остаются ссылками
deep = copy.deepcopy(original)  # копирует всё вложенное
```

Неизменяемые (`int`, `str`, `tuple`) так не «протекают» — передача всегда
создаёт новое значение локально.

---

## 7. Какие типы применять когда

- Одиночное значение — `int` / `float` / `str` / `bool`.
- Набор не связанных однотипных значений — `list`.
- Набор, который не должен меняться — `tuple`.
- Пара ключ→значение — `dict`.
- Уникальность / быстрая проверка вхождения — `set`.
- «Число или ничего» — `int | None` (или `float | None`).

## Чтобы проверить себя

```python
# Что выведется? Попробуй угадать до запуска.
a = [1, 2, 3]
b = a  # ссылка
c = a.copy()  # копия
b.append(4)
print(a, b, c)

t = (1, [2, 3])  # кортеж с изменяемым элементом
t[1].append(4)  # работает! кортеж запрещает менять САМИ элементы,
print(t)  # но не содержимое изменяемых элементов
```
