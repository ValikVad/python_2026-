## 🎓 Принципы ООП, которые тут спрятаны

| Принцип | Где в коде |
|---|---|
| **Базовый класс** | `Figure` хранит общую логику: поворот, `cells`, `__eq__` |
| **Наследование** | `class FigureI(Figure)` — наследник получает методы базы |
| **`super().__init__`** | наследник делегирует заполнение общих полей родителю |
| **Полиморфизм** | `rotated()` делает экземпляр `type(self)`; `Board` вызывают `figure.cells`, `SYMBOL` не зная тип |
| **Атрибуты класса** | `COLOR`/`SYMBOL` общие для всех `FigureI`, но разные у разных фигур |

### Подсказки-правила
- Не переопределяй `rotated()`, `cells`, `__eq__` у наследников — это трогаешь **только в базе**.
- Наследник — это «данные + super().__init__», а не копия всей логики. Если дублируешь
  поворот в трёх фигурах — делаешь неправильно.
- `rotated()` должен возвращать **тот же подкласс**: поворот `FigureI` → снова `FigureI`.
