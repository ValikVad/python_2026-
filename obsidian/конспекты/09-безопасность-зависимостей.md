## Что именно фиксирует uv.lock

| Уровень         | Что он определяет                 |
| --------------- | --------------------------------- |
| Версии          | Прямые и транзитивные зависимости |
| Источники       | Откуда брать выбранные пакеты     |
| Хеши артефактов | Какие файлы ожидаем получить      |

Для обычных пакетов из индекса.

**Хеш подтверждает содержимое. Вредоносный файл тоже имеет правильный хеш.**

## Выбор индекса в uv

**`first-index` по умолчанию:** версии берутся из первого индекса, где найден пакет.

```toml
[tool.uv.sources]
acme-core = { index = "internal" }

[[tool.uv.index]]
name = "internal"
url = "https://packages.example.com/simple"
explicit = true
```

Условный внутренний пакет явно привязан к источнику.

## Обновление как отдельное решение

```bash
uv lock --upgrade-package httpx
# Проверка изменений uv.lock и тесты
uv sync --locked
uv run --locked pytest
```

При новом разрешении можно задержать свежие публикации:

```toml
[tool.uv]
exclude-newer = "7 days"
```

Задержка даёт время на обнаружение атаки, но откладывает и исправления.

## Сборка тоже выполняет код

**sdist:** исходники, build backend и его зависимости.

**wheel:** готовый артефакт без локальной сборки исходников.

```bash
uv sync --locked --no-build
```

Если потребуется сборка, команда завершится ошибкой.

Виртуальное окружение изолирует пакеты. Права на файлы и сеть остаются у процесса.

## Один lock-файл, разные окружения

```text
Условный граф зависимости codec:
Python < 3.12     codec==1.8
Python >= 3.12    codec==2.4
```

uv сохраняет условные ветви и выбирает подходящую при установке.

Разрешитель **PubGrub** учитывает ограничения и разбирает конфликты.

Совместимый по метаданным граф ещё нужно проверить тестами.

## Откуда берётся скорость

Rust, параллельные операции и повторное использование кэша.

**Нюанс:** uv по умолчанию пропускает компиляцию `.pyc` при установке.

```bash
uv sync --locked --compile-bytecode
```

Для честного сравнения: одинаковые зависимости, кэш и настройки компиляции.

Скорость установки и скорость Python-программы измеряются отдельно.

## Скрипт с собственным окружением

```python
# /// script
# requires-python = ">=3.12"
# dependencies = ["rich"]
# ///
from rich import print
print("[green]Один файл, явные зависимости[/green]")
```

```bash
uv lock --script demo.py
uv run --locked demo.py
```

PEP 723 описывает требования. `demo.py.lock` фиксирует решение.

## Что проверять в dependency PR

- Какие транзитивные пакеты появились?
- Сохранились ли ожидаемые источники?
- Понадобится ли сборка из исходников?
- Прошли ли тесты на целевых версиях Python?

**uv делает выбор зависимостей явным и повторяемым. Доверие к новому коду требует отдельной проверки.**
