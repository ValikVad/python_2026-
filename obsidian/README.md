- **Пакеты/окружения:** `uv` + `pyproject.toml`

- **Типизация:** `mypy` (strict)
- **Тесты:** `pytest`
- **Хуки перед commit:** `pre-commit`
- **CI:** GitHub Actions (проверка на каждый push)
