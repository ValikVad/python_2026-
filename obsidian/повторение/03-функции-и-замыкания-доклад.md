# Доклад · Функции, *args/**kwargs, замыкания, области видимости

> Повторение и систематизация темы №3 ядра языка.

---

## 1. Функция — объект первого класса

Функции можно передавать в аргументы, возвращать и присваивать переменным.

```python
def add(a, b):
    return a + b

f = add          # ссылка на функцию
f(1, 2)          # 3
```

## 2. Аргументы: виды и порядок

Жёсткий порядок объявления:

```
def f(pos, /, pos_or_kw, *, kw_only):
```

- **Позиционные + ключевые (обычные):** `def f(a, b)`.
- **Только позиционные** — `/` (до слеша, 3.8+).
- **Только ключевые** — `*` (после звёздочки).
- **Значения по умолчанию** — необязательные:

```python
def greet(name, punctuation="!"):
    return f"Привет, {name}{punctuation}"
```

## 3. `*args` — произвольное число позиционных

Собирает в **кортеж**:

```python
def total(*nums):
    return sum(nums)

total(1, 2, 3)   # 6
```

## 4. `**kwargs` — произвольное число именованных

Собирает в **словарь**:

```python
def info(**kw):
    for k, v in kw.items():
        print(k, v)

info(name="Аня", age=20)
```

**`*` распаковка при вызове:**
```python
def add(a, b, c): ...
args = [1, 2, 3]
add(*args)           # add(1,2,3)
kw = {"a": 1, "c": 3, "b": 2}
add(**kw)            # ключевыми
```

## 5. Области видимости (LEGB)

Порядок поиска имени: **L**ocal → **E**nclosing → **G**lobal → **B**uilt-in.

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        return x
    return inner
```

### `global` и `nonlocal`

```python
count = 0
def inc():
    global count     # чтобы менять ГЛОБАЛЬНУЮ переменную
    count += 1

def outer():
    n = 0
    def inner():
        nonlocal n   # чтобы менять переменную ВНЕШНЕЙ функции
        n += 1
        return n
    return inner
```

> Без `global`/`nonlocal` операция `x += 1` создаст **новую локальную** переменную, а не изменит внешнюю.

## 6. Замыкания (closures)

Функция «запоминает» переменные из охватывающей области даже после выхода из неё.

```python
def make_multiplier(factor):
    def multiplier(x):
        return x * factor   # factor "захвачен"
    return multiplier

double = make_multiplier(2)
double(5)   # 10
```

**Счётчик через замыкание:**
```python
def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter
```

## 7. Lambda (анонимные функции)

Однострочная функция без имени. Хороша для передачи как аргумент.

```python
square = lambda x: x**2
sorted(items, key=lambda x: x[1])
```

## 8. Декораторы (функция-обёртка)

Обёртка, добавляющая поведение без изменения исходной функции.

```python
def log(func):
    def wrapper(*args, **kwargs):
        print("вызов:", func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log
def greet(name):
    return f"Привет, {name}"
```

## 9. Возвращаемые значения

- `return` — возвращает значение; без него — `None`.
- Можно вернуть кортеж для «нескольких» значений.
- Вложенные функции (замыкания) могут вернуть внутреннюю функцию.

## 10. Антипаттерны и нюансы

1. **Изменяемый дефолт:** `def f(x, lst=[]):` — баг (см. тему типов).
2. `return` и `yield` в одной функции — нельзя смешивать осмысленно.
3. `*args` — всегда кортеж; `**kwargs` — всегда словарь.
4. Менять глобал без `global`/`nonlocal` — нельзя.

---

## Шпаргалка «Функции наизусть»

1. Порядок: `pos`, `*args`, ключевые с дефолтом, `**kwargs`.
2. `*args` = кортеж, `**kwargs` = словарь.
3. Вызов: `f(*lst)` и `f(**dict)` — распаковка.
4. LEGB: Local → Enclosing → Global → Built-in.
5. `global` — меняем глобальную; `nonlocal` — меняем внешнюю.
6. Никогда `def f(x, lst=[])` — изменяемый дефолт.
7. Замыкание «помнит» внешнюю переменную.
8. `lambda` — анонимная однострочная функция.
9. Декоратор — функция, оборачивающая функцию.
10. Без `return` функция возвращает `None`.
